MLXP
Data Manager

Data Manager는 ML 워크로드에서 사용하는 HuggingFace 인터페이스의 데이터셋 관리 시스템입니다. NAVER Cloud ML expert Platform(MLXP)의 일부로, 사내 GPU·데이터 파이프라인 플랫폼에서 테라바이트 단위의 데이터셋을 다룹니다.

저는 이 프로젝트에서 워크스페이스별 쿼터 관리 로직 개발을 주도했습니다. 데이터셋 용량과 파일 개수를 정교하게 제어하고, 사용자·데이터셋별 스토리지 사용량을 추적하며, 쿼터 미터링으로 이용 패턴 분석과 어뷰징 방지까지 연결했습니다.
